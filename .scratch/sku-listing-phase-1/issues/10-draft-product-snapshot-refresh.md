# 10: 未生效草稿重新带入商品资料

Status: ready-for-agent

**What to build:** 采购和订单人员主动比较未生效草稿与当前商品主数据，确认后刷新允许的商品资料，保留历史单据和业务输入。

**Blocked by:** 08：采购有效 SKU 选品与存量采购履约；09：手工订单有效 SKU 选品与存量履约。

- [ ] 未生效采购草稿和订单草稿提供「重新带入商品资料」，预览逐行名称、规格、单位及本单使用的重量/包装/申报资料差异，确认后才更新。
- [ ] 不更换 SKU、不重新解析配对，不改变数量、单价、税费等业务输入；锁定身份和单位不会因刷新改变口径。
- [ ] 已审批采购，以及已支付、已有资金记录、预占、旧履约计划、WMS 作业或实发影响的订单拒绝刷新。不能利用刷新绕过 SKU 更正前置条件。
- [ ] 当前 SKU 停用或资料不满足该草稿生效条件时明确提示；刷新不能使停用商品取得新的有效性或扩大旧单需求。
- [ ] 实际物流单称重和包装记录、已存历史快照不被覆盖；旧单缺失历史资料时显示来源或缺失标记，不宣称当前值是原始事实。
- [ ] 确认时核对主数据及草稿版本、权限和生效状态；预览后支付、审批或资料变化时拒绝旧预览提交，失败不部分更新。记录操作者、时间及差异。
- [ ] HTTP API 验证两类草稿刷新、历史不变、用户业务字段保留、竞争及权限；网页演示改主数据、查看差异、确认刷新与生效单据拒绝的完整过程。

## Comments

本任务不更换订单商品。标准订单的受控 SKU 更正由 16 交付。
