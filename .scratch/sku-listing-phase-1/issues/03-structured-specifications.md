# 03: 共享规格字典与单 SKU 组合维护

Status: ready-for-agent

**What to build:** 商品维护人员在中央维护颜色、尺寸等规格属性和值，为 SPU 选择规格范围，再使用结构化组合建档或编辑 SKU。

**Blocked by:** 02：SKU 启停、身份锁与有效商品契约。

- [ ] 网页可维护本租户共享规格属性及值，SPU 可选择适用维度和可选值；使用商品维护权限，跨租户 ID 和重复/无效字典引用被拒绝。
- [ ] 同一 SPU 内按稳定属性/值集合判重，交换属性输入顺序不会创建另一组合；草稿、启用、停用商品都占用其既有组合。
- [ ] 普通单规格商品不强制填写规格；多规格商品仅接受 SPU 允许的属性和值，不以自由文本或不同显示顺序规避组合唯一性。
- [ ] 仅草稿且无引用可更换组合或归属；已启用/引用后直接 API、字典操作或父级改动均不能把原 SKU 变成另一个规格身份。
- [ ] 被引用的属性/值不能删除或改造成另一含义；允许的描述性更名不改变稳定身份及历史单据快照。调整 SPU 可选范围不能使既有锁定 SKU 成为非法组合。
- [ ] 整合现有 ProductVariant 的规格表现与 Sku 库存身份，旧变体接口不能形成独立启用状态或另一库存编码。历史自由文本规格先出冲突清单，不盲目归并。
- [ ] SKU 列表、SPU 详情、维护弹窗显示同一份结构化规格；错误提示定位冲突的既有 SKU。
- [ ] HTTP API 验证组合顺序无关、跨状态重复、锁定及字典引用保护；网页建立属性和值、配置 SPU、创建和编辑一个合法草稿组合，并验证重复拒绝。

## Comments

本任务交付单个组合闭环；笛卡尔积预览与批量创建由 04 交付。
