# 14: 按 ASIN 展开已有 MSKU 后批量配对

Status: ready-for-agent

**What to build:** 运营人员在配对 Excel 选择 ASIN 模式，把明确店铺/站点范围内已有 Listing 展开为 MSKU，逐条确认后按同样原子规则配对。

**Blocked by:** 13：按 MSKU 导入并受控覆盖当前配对。

- [ ] 同一配对导入入口提供 MSKU、ASIN 两种明确模式；ASIN 模式按所选店铺及站点查询系统已有 Listing，不调用 SP-API、不自动拉取或创建远端商品。
- [ ] 一个 ASIN 在所选范围存在两个 MSKU 时，预览逐条显示范围、MSKU、旧目标和该行指定的新目标；不能只显示 ASIN 汇总并隐藏影响。
- [ ] 无匹配 Listing、缺少店铺/站点或身份不确定时返回明确错误；未选店铺/站点的关系完全不受影响。目标本地 SKU 必须已启用且在当前租户。
- [ ] 多个输入行展开到同一范围/MSKU 重复或不同目标时拒绝，不允许展开顺序决定覆盖结果。
- [ ] 保留新增/覆盖确认、全量预校验、版本检查、历史和重试语义；确认前 Listing 集合或映射变化时重新预览，不把新出现的 MSKU 自动纳入旧确认范围。
- [ ] 展开的全部关系及历史原子提交，任一 MSKU 失败整批不变；已有标准订单保持旧快照，不自动重放。
- [ ] HTTP API 使用真实 Excel 验证一 ASIN 多 MSKU、显式范围、无匹配、展开冲突、集合变化及全量回滚；网页完成模式切换、逐 MSKU 预览和确认后查询。

## Comments

仅扩展配对导入的展开规则，不复制另一套提交、审计或错误反馈机制。
