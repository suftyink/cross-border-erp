# 07: 同一 Excel 创建新 SPU 与多条 SKU

Status: ready-for-agent

**What to build:** 商品维护人员在统一 SKU 模板中填写完整新 SPU 资料，预览后一次创建 SPU 及其多个草稿 SKU，也可以混合更新既有商品。

**Blocked by:** 06：统一 SKU Excel 预览与原子新增更新。

- [ ] 以明确 SPU 编码归组新商品，要求新 SPU 名称和已存在的分类完整；品牌可空，非空品牌必须已存在。不按相似名称或省略信息猜测归属。
- [ ] 同一新 SPU 下两行 SKU 共用一个父记录，组内名称/分类/品牌一致；组内矛盾、SPU 编码冲突、未知字典及资料不足在预校验报告行号和原因。
- [ ] 预览区分新 SPU、新 SKU、既有 SKU 更新，并显示继承后的最终资料；既有 SPU 共用字段仍不得通过 SKU 文件覆盖。
- [ ] 新 SPU、新 SKU、规格关系及既有商品更新在整个文件同一事务中生效；任一行失败，全部回滚，不留下空 SPU 或部分更新。
- [ ] 提交时再次检查 SPU 是否被并发创建、规格及编码唯一性、字典和权限；变化后重新预览，不把新建意图静默改成更新其他人的 SPU。
- [ ] 保留新 SKU 草稿、既有 SKU 不改状态、空白保持及显式清空规则；相同确认重试无重复父子数据。
- [ ] HTTP API 在实际数据库验证一父两子、混合新增更新、组内不一致、并发及全量回滚；网页完成同模板新建 SPU+两个 SKU，结果可在 SPU 详情和独立 SKU 页核对。

## Comments

这是统一导入流程的扩展，不引入隐式字典创建或导入直接启用。
