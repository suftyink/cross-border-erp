# 06: 统一 SKU Excel 预览与原子新增更新

Status: ready-for-agent

**What to build:** 商品维护人员下载同一模板，对既有 SPU 下的 SKU 按本地编码新增或更新，预览确认后整批生效。

**Blocked by:** 03：共享规格字典与单 SKU 组合维护；05：商品必要属性、图片与分阶段完整性。

- [ ] 网页提供模板下载、文件上传、全量预校验、逐行差异/错误预览及确认；按规范化本地编码新增或更新，不分成两套互斥导入模式。
- [ ] 未知分类、品牌、规格属性/值、非法或越权 SPU、文件内重复编码/组合均报出行号、字段和原因；不自动创建字典。已有 SPU 共用字段空白时继承，非空不一致时报错。
- [ ] 更新行空白保持原值，`#CLEAR` 仅清空允许清空的可选字段且预览明确标注；不能清空必填、锁定身份或通过 SKU 文件改写既有 SPU 名称/分类/品牌。
- [ ] 新 SKU 为草稿，既有 SKU 状态保持；非空状态变更指令提示使用列表启停。编码、SPU 和规格的更新沿用身份锁，不能通过导入绕过。
- [ ] 资料支持规格、单位、必要物流/包装/申报字段、条码和图片 URL；不接受 ZIP 图片匹配。模板及预览说明每列单位和空值语义。
- [ ] 预校验不落业务数据，确认绑定预览版本、文件和操作者；确认时重新检查权限、商品/字典版本、目标状态、唯一性和锁，变化后要求重新预览。
- [ ] 整个文件业务变更同一事务提交；一行失败、持久化失败或最后一行冲突均无部分新增/更新。同一次确认重试不会创建重复数据，不能边读 Excel 边提交业务批次。
- [ ] HTTP API 上传真实 Excel 验证混合新增更新、空值/清空、锁定、字典错误、并发变化及全量回滚，并在实际数据库验证事务和唯一性；网页完成模板下载、错误修正、差异确认及查询结果核对。

## Comments

本任务先支持既有 SPU；同一模板中新建 SPU 的能力由 07 在本流程上扩展，不新增另一套导入界面或提交协议。
