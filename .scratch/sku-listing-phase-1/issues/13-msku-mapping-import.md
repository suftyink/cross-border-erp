# 13: 按 MSKU 导入并受控覆盖当前配对

Status: ready-for-agent

**What to build:** 运营人员使用配对 Excel 按明确店铺、站点和 MSKU 建立或覆盖关系，逐行确认旧→新差异后整批生效。

**Blocked by:** 12：人工商品配对、改配与历史追溯。

- [ ] 网页提供模板、上传、全量预校验、变动预览与确认。显式选择授权店铺及站点，可明确多选；不把空范围解释成全部店铺。
- [ ] 按精确 MSKU 定位已有渠道商品，校验身份可确定、目标本地 SKU 已启用且属于本租户；MSKU 不转大写。文件内同一最终范围/MSKU 重复或冲突时报错，不采用最后一行获胜。
- [ ] 允许新增关系以及将现有目标由 SKU-A 覆盖成 SKU-B，预览展示每条范围/MSKU、旧目标、新目标与操作类型；用户明确确认覆盖，这是已确认的领星导入策略。
- [ ] 预校验不修改关系；未知对象、越权范围、停用目标、重复行、无效输入显示行号及原因，任一错误阻止整批确认。
- [ ] 确认绑定文件、预览版本和操作者，再检查权限、当前映射版本及 SKU 状态；期间关系或状态变化要求重新预览，不能静默扩大/覆盖影响。
- [ ] 整个文件的当前关系和历史记录同一事务生效；最后一行失败时前面全部不变。同一次确认重试不重复历史或关系。
- [ ] 旧标准订单快照不因覆盖改变；新解析获得新目标。导入不启停 SKU，不自动重处理订单、支付、发货或操作远端 Listing。
- [ ] HTTP API 使用真实 Excel 验证新增+覆盖、重复、权限、版本变化、幂等及实际数据库全量回滚；网页演示旧→新确认和错误修正，再核对关系历史。

## Comments

这里只要求已有渠道商品身份可定位，不拉取或凭空创建亚马逊远端记录。按 ASIN 展开由 14 在同一导入流程扩展。
