# 05: 商品必要属性、图片与分阶段完整性

Status: ready-for-agent

**What to build:** 商品维护人员能维护图片、条码、重量尺寸、包装和申报资料，后续已有业务在真正需要时提示缺项。

**Blocked by:** 02：SKU 启停、身份锁与有效商品契约。

- [ ] 支持图片、外部 UPC/EAN 等条码、重量、商品及包装尺寸、箱规/装箱数量、申报资料与备注；展示明确单位，分类和品牌仍来自 SPU。
- [ ] 重量、尺寸及金额使用适当小数类型并拒绝非法负值；库存数量仍是整数且只有一个基本库存单位。箱规不产生箱/件换算或库存变动。
- [ ] 网页可以上传图片或填写图片 URL，列表/详情正确预览、更新与移除。复用现有文件存储，检查租户、权限、文件类型及大小。
- [ ] 上传图片保存稳定对象引用并在查看时取得有效地址，签名链接过期后仍可重新查看；不把一小时有效链接当永久图片地址。外部 URL 不触发服务端任意地址抓取。
- [ ] 草稿可以缺少资料；启用仅检查已确认的基础字段。真正依赖重量/申报等资料的已有业务操作在使用点拒绝缺项并指出具体 SKU/字段，不为此新增完整物流或报关流程。
- [ ] 编辑描述、重量、图片或包装不改变商品身份或状态；历史单据不随当前主数据查询而改写，后续单据按快照契约读取资料。
- [ ] HTTP API 验证可选资料、数值边界、租户/权限、上传校验及稳定图片引用；网页演示上传与 URL 两条路径、保存刷新、修改资料和使用阶段缺项提示。

## Comments

Excel 只导入图片 URL；无 ZIP 对图、图片文件名匹配或保质期/序列号控制。具体单据快照在 08、09 建立，主动刷新在 10 交付。
