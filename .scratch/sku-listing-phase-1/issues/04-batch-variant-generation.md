# 04: 规格组合预览与批量生成草稿

Status: ready-for-agent

**What to build:** 商品维护人员选择 SPU 的规格值后预览组合，只勾选需要的新组合并批量生成草稿 SKU。

**Blocked by:** 03：共享规格字典与单 SKU 组合维护。

- [ ] 颜色两值、尺寸两值时预览四个组合；已有组合显示对应编码和状态且不可重复生成，包含已有停用组合。
- [ ] 可以勾选部分尚不存在的组合；可生成或填写各自编码与名称，所有编码沿用规范化、租户唯一性和字符约束。
- [ ] 提交只创建勾选的新 SKU，全部为 DRAFT，共用指定 SPU 的分类和品牌，不隐式启用、生成库存或新建字典。
- [ ] 预览不落业务数据；提交时重新校验属性范围、组合唯一性、编码冲突和权限。预览后已有组合被其他人创建时，显示冲突并要求更新预览，不重复创建。
- [ ] 一次生成操作原子完成，失败不留下部分 SKU；同一次确认重试不重复造数。
- [ ] 新草稿在独立 SKU 列表和 SPU 详情立即可查，可继续按既有生命周期启用。
- [ ] HTTP API 覆盖已有组合、选择子集、非法属性、编码冲突、竞争及重试；网页演示四组合中已有一个、只选两个新组合的完整生成过程。

## Comments

不实现虚拟套装或 BOM；每个生成的组合都是一个独立库存 SKU。
