# 04: 规格组合预览与批量生成草稿

Status: resolved

**What to build:** 商品维护人员选择 SPU 的规格值后预览组合，只勾选需要的新组合并批量生成草稿 SKU。

**Blocked by:** 03：共享规格字典与单 SKU 组合维护。

- [x] 颜色两值、尺寸两值时预览四个组合；已有组合显示对应编码和状态且不可重复生成，包含已有停用组合。
- [x] 可以勾选部分尚不存在的组合；可生成或填写各自编码与名称，所有编码沿用规范化、租户唯一性和字符约束。
- [x] 提交只创建勾选的新 SKU，全部为 DRAFT，共用指定 SPU 的分类和品牌，不隐式启用、生成库存或新建字典。
- [x] 预览不落业务数据；提交时重新校验属性范围、组合唯一性、编码冲突和权限。预览后已有组合被其他人创建时，显示冲突并要求更新预览，不重复创建。
- [x] 一次生成操作原子完成，失败不留下部分 SKU；同一次确认重试不重复造数。
- [x] 新草稿在独立 SKU 列表和 SPU 详情立即可查，可继续按既有生命周期启用。
- [x] HTTP API 覆盖已有组合、选择子集、非法属性、编码冲突、竞争及重试；网页演示四组合中已有一个、只选两个新组合的完整生成过程。

## Comments

不实现虚拟套装或 BOM；每个生成的组合都是一个独立库存 SKU。


## Answer

完成日期：2026-11-21。任务 03 已核验并独立提交为 `cd3f4c4`，本任务在该基线上交付。

- SPU 详情及独立 SKU 页选定 SPU 后，可从「批量生成规格 SKU」选择范围、预览笛卡尔积、勾选新组合，并逐行填写或生成编码及名称。已有组合显示真实编码和状态，停用组合仍不可选。
- 预览仅保存绑定租户、SPU、操作人和范围摘要的技术快照，不创建 SKU、字典或库存。预览有效期 30 分钟，单次最多 200 个组合。
- 确认时校验预览归属、时效、SPU／字典范围、组合占用、编码规范化及租户唯一性；选中行通过原有建档用例创建 DRAFT，并继承父级分类和品牌。范围或组合已被其他操作更改时拒绝并要求更新预览。
- 整批 SKU、规格、历史及确认回执在同一事务提交。任一后续行失败会回滚前面已创建的商品；未成功的预览可修正后重试。相同确认重试返回原回执，变更已确认内容会被拒绝；回执不会因预览时效结束而重新造数。
- 两个入口立即刷新；网络结果不明时保留原提交内容并提供「重试确认」。沿用商品维护权限，绑定登录租户和操作人。规格 key 提取为共用逻辑，避免单个和批量建档判重不一致。
