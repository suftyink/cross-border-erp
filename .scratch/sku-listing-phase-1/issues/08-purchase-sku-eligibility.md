# 08: 采购有效 SKU 选品与存量采购履约

Status: ready-for-agent

**What to build:** 采购员选择正式有效 SKU 建单，采购商品资料保留快照；停用阻止新增采购需求，但已审批采购在原范围内可以完成收货和退供补货。

**Blocked by:** 03：共享规格字典与单 SKU 组合维护；05：商品必要属性、图片与分阶段完整性。

- [ ] 采购单网页将自由填写编码改为有效本地 SKU 搜索选择，显示名称、规格、单位及状态；后端批量校验 SKU 属于当前租户且已启用。
- [ ] 创建、新增/改增采购需求及未审批单的提交、审批关口重新检查有效性；选择后商品停用或直接调用接口均不能建立新需求。商品编码不被供应商跳转或其他建单入口绕过。
- [ ] 商品被停用前已审批采购可按原已审批范围继续分批收货、质检、上架、退供及合法补货；新增或增加采购需求重新检查，不能借旧单采购更多停用商品。
- [ ] 采购行保存商品身份及当时名称、规格、单位、该单据使用的重量/包装/申报资料。之后修改主数据不改变原快照或原采购编码，历史缺失不得伪造为真实当时资料。
- [ ] 以正式有效 SKU 更新相关测试夹具及本功能所需的仿真数据，不能通过关闭 SKU 校验维持旧自由编码测试；实际数据变更前核对冲突与备份。
- [ ] 收货、库存及退供补货沿用现有 WMS 唯一过账和收货批次追溯，选品/停用不产生库存流水，不新增采购模块直接增库存路径。
- [ ] HTTP API 覆盖不存在/跨租户/停用 SKU、状态变化竞态、已审批与未审批的不同结果、原单补货和快照；网页演示选品建单、停用后草稿审批被阻止、已审批原单继续分批收货。

## Comments

需保留已有供应商跳转筛选和采购单查询改动。主动将最新资料带入未生效采购草稿由 10 交付。
